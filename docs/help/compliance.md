# ASCE Compliance Panel

## What it does
Checks your hull against the ASCE Competition Rules and colour-codes each rule as **PASS**, **WARN**, or **FAIL**.

## Rules checked
| Rule | Description |
|------|-------------|
| Length limit | Hull ≤ maximum length (ft) |
| Freeboard | ≥ 6 in above waterline with crew aboard |
| Buoyancy margin | Displacement ≥ system weight × safety factor |
| Mix density range | All mix densities within 60–120 pcf |

## How to use
1. Complete the Structural Sweep first — the compliance panel reads the sweep result.
2. Switch to the **③ ASCE Compliance** tab.
3. Review any FAIL or WARN items and adjust your hull parameters.

## Colour key
| Colour | Meaning |
|--------|---------|
| Green | Rule satisfied |
| Yellow | Within 10% of the limit — review recommended |
| Red | Rule violated — hull ineligible for competition |
